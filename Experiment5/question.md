# K-Nearest Neighbors (KNN) for Image Classification

## Objective

Implement the **K-Nearest Neighbors (KNN)** algorithm for image classification using the **Fashion MNIST** dataset. Experiment with different values of **K** and analyze their impact on model performance.

## Tasks

1. Load and preprocess the **Fashion MNIST** dataset.
2. Implement **KNN** for multi-class image classification.
3. Experiment with different values of **K**.
4. Analyze the impact of different **K** values on:
   - Model accuracy
   - Computational efficiency
5. Compare the performance of the KNN models and discuss the results.
